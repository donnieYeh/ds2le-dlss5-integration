DS2LE DLSS5 接入

1. 先安装 DS2LightingEngine（DS2LE）光追版。
2. 备份游戏 Game 目录中的 DINPUT8.dll、dxgi.dll 和 ReShade.ini。
3. 将原版游戏 DINPUT8.dll 重命名为 dinput8_orig.dll。
4. 将本包的 DINPUT8.dll 复制到同一个 Game 目录。
5. 按 README.md 中的上游链接下载 dlss5-bridge.addon64、
   renodx-dlss5.addon64 和 nvngx_dlssnr.dll，并复制到 Game 目录。
6. 将 ReShade.ini.example 中的两个配置段合并到现有 ReShade.ini，
   不要覆盖 DS2LE 的其他设置。
7. 正常启动游戏；每个 addon 只保留一份。

回滚：退出游戏，删除本项目的 DINPUT8.dll，恢复原版 DINPUT8.dll 和
ReShade.ini；第三方 addon 按备份删除或恢复。
